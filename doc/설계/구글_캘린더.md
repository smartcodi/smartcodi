# 구글 캘린더 연동

> `CLAUDE.md`에서 분리한 기능 설계 문서(2026-09-29). 이 기능의 코드를 고치기 전에 읽고, 동작을 바꾸면 이 문서도 같이 고친다.

Google Calendar 커넥터는 2026-09-28에 업무용 구글 계정으로 연결됐다. **일정은 활동의 한 종류**로 다룬다(사용자 요청): «할 일 → 달력»이 구글 캘린더를 보여 주고, 보드 예정일을 캘린더에 올리면 활동(`channel:'calendar'`)으로 기록된다.

- **읽기** — `mcp.watchTool('Google Calendar', 'list_events', …)`로 **보는 사람의 기본 캘린더**를 월 그리드(6주) 범위로 읽는다. 5분마다 다시 읽고, 달을 옮기면 watch를 새로 건다(`ensureCalWatch`). 칩 종류: 색 칩 = 보드가 등록한 일정(활동의 `eventId`와 일치 → 과제 상세로), 회색 칩 = 그 밖의 일정(→ 구글 캘린더), 점선 칩 = 캘린더에 없는 보드 예정일(미등록·날짜 변경).
- **쓰기** — 표의 «등록»은 `create_event`(종일, `startTime`=예정일 `T00:00:00`, `endTime`=다음날, `timeZone:'Asia/Seoul'`)를 호출한다. «날짜 수정»은 보드 예정일이 등록된 날짜와 달라졌을 때 나오며 `update_event`를 호출한다. 둘 다 응답에 이벤트 `id`가 있을 때만 활동을 남긴다. **삭제는 페이지에 넣지 않는다.**
- **단방향이다.** 구글 캘린더에서 직접 옮기거나 지운 일정은 보드 예정일에 반영되지 않는다. 날짜의 기준은 보드 예정일이다.
- **캘린더 시간대가 UTC**라 모든 호출에 `Asia/Seoul`을 준다. 실측 응답 모양(2026-09-28): `list_events` → `{events:[…]}`, 종일은 `start.date = "YYYY-MM-DDT00:00:00Z"`, 시각 일정은 `start.dateTime = "…+09:00"`(요청에 시간대를 줬을 때), 삭제된 일정은 `status:"cancelled"`로 올 수 있어 걸러 낸다(`evParts`/`evDays`).
- **커넥터가 없는 화면**(`use('mcp')`가 null)이나 읽기 거부 시에는 대체 경로를 쓴다:
  1. **건별** — `gcalUrl(r)`이 `calendar.google.com/calendar/render?action=TEMPLATE&…` 링크를 만든다. 종일 일정이고 `dates`의 종료일은 배타적이라 `예정일 + 1일`을 넣는다.
  2. **일괄** — 구글 캘린더 가져오기용 CSV. 헤더는 `Subject,Start Date,End Date,All Day Event,Description`, 날짜는 `MM/DD/YYYY`, **BOM을 붙이지 않는다**(`csvBtn(..., {bom:false})`). BOM이 있으면 구글이 첫 헤더를 못 읽는다. 반대로 엑셀용 CSV(보고서 탭)는 BOM이 있어야 한글이 안 깨지므로 기본값 `true`를 쓴다.
- 일정 제목·본문은 `gcalTitle`/`gcalDetails` 한 곳에서 만든다(링크·등록 공용).

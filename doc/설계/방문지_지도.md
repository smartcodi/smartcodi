# 방문지 · 지도

> `CLAUDE.md`에서 분리한 기능 설계 문서(2026-09-29). 이 기능의 코드를 고치기 전에 읽고, 동작을 바꾸면 이 문서도 같이 고친다.

- **방문지 = `visitOf(p)`** 한 곳에서 정한다. 1순위 과제 구축지 `p.visit.address`(사업계획서의 "구축지 주소"가 본사와 다를 때), 2순위 소공인 기관의 `address`, 둘 다 없으면 없음. 과제 상세 «방문지» 섹션에서 기관 주소 입력 / 구축지 따로 입력 / «기관 주소 사용»(구축지 삭제)을 한다.
- **지도는 새 탭 링크로만 연다.** 카카오·네이버 지도 JS SDK와 우편번호 검색(daumcdn)은 CSP 허용 목록 밖이고 앱 키도 필요하다. 주소는 텍스트로 입력한다.
  - 대중교통 길찾기(구글, 공식 Maps URLs): `https://www.google.com/maps/dir/?api=1&destination=<주소>&travelmode=transit[&origin=<출발지>]`
  - 네이버 `https://map.naver.com/p/search/<주소>` · 카카오 `https://map.kakao.com/link/search/<주소>` — **좌표 없이는 경로 화면을 바로 열 수 없어 주소 검색 화면까지만** 연다(거기서 '도착'을 눌러 국내 대중교통 경로). 버튼 툴팁에 적어 뒀다.
  - 목적지로는 **도로명 주소만** 넘긴다(상세 "3층 301호"를 붙이면 검색이 실패하기 쉽다). 복사·캘린더 location·메일 본문에는 상세까지 넣는다(`fullAddr`).
- **출발지**는 보는 사람별 편의 설정이라 `localStorage['smartcodi.origin']`. 공유 데이터가 아니다.
  - **비워 두면 현재 위치를 자동으로 넣는다**(2026-09-28 사용자 요청): 출발지 칸이 처음 그려질 때 `navigator.geolocation`으로 한 번 찾고(`locateHere`, 첫 호출에 브라우저 권한 창), 구글 길찾기 `origin=위도,경도`로 넣는다(`originForMap`). 좌표는 화면 메모리에만 두고 저장하지 않는다.
  - 우선순위: 입력한 출발지 > 현재 위치(자동) > origin 없이 열기(구글 지도가 기기 위치로 잡음). 위치를 못 얻으면 «위치 권한이 없어…» + «다시 찾기». 입력한 출발지가 있으면 «현재 위치로» 버튼.
  - claude.ai 화면이 위치 권한을 막으면 항상 마지막 경로가 된다(실제 보드에서 확인 필요). 네이버·카카오는 목적지 좌표가 없어 여전히 주소 검색 화면까지만 연다.
- 연계: 방문 단계(1·2·7·8)의 «일정» 표에 «길찾기», 캘린더 등록에 `location`, 메일 `일정 조율`·`일정 안내`에 `· 방문지:` 줄(주소가 있을 때만).
- 예시 데이터에는 주소를 넣지 않았다(지어내지 않는다). 실제 주소는 사용자가 입력한다.

- 출발지 칸은 `originControl`이 그린다(인수인계 2026-09-29에서 옮김).

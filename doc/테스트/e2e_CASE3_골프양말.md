# E2E-03 · CASE 3 (필수) — 골프 양말 / 봉조 자동화 편직기

공통 규칙·사전 조건은 [README](README.md). 중점: **실무 결정권자(이사)를 소공인 담당자로**, **구글 캘린더 등록·날짜 수정**, **전화번호 통합 검색**, **견적서 오기(誤記) 처리**.

## 사례 요약 (PDF 4쪽)

- 골프 양말 위주 특화 상품. 봉조 공정을 내부 인력으로 진행 → 인건비·원가 부담
- 연매출 **2억원 이상**, 총 6명 → **원공고**
- 자동 봉제 불가 기기 23대 보유, 본 사업으로 **2대 교체** 후 순차 교체
- 실제 경영은 **대표보다 담당 이사의 전문성이 높음**. 창업 5년 이내

| 구분 | 품목 | 수량·단위 | 단가 | 공급가 | 비고 |
|---|---|---|---:|---:|---|
| H/W | 하이테크(컴퓨터) 양말편직기 — Smart Socks Knitting Machine, 커즌(Kejun), Auto-linking System(발가락 자동봉조공정 통합형), 2개 장치(1세트) | 2 대 | 21,000,000 | 42,000,000 | 납기 **입금 후 30일 이내**, A/S 12개월 무상 |
| S/W | YARNCHAIN GRID 프로그램 (무선 설비 모니터링 등) + 현장 키오스크 단말 + 현장 설치·시운전 | — | — | 6,000,000 | 부가세 600,000 / 합계 표기 `6,600,00원` |

**원문 오기**: S/W 합계가 `6,600,00원`으로 인쇄됨(자릿수 누락). 보드에는 **공급가 6,000,000(VAT 별도)**를 입력하고 오기를 메모로 남긴다. 합계를 추정해 고쳐 쓰지 않는다.

## 보드 밖 확인

- S/W 한도 = 4,666,666 / S/W 6,000,000 → **초과 1,333,334**
- 서명 주체: 사업계획서·수행일지 서명란은 "신청인(대표)"이다. 이사가 실무자라도 서명은 대표 — 보드 초안의 서명란이 `신청인(대표) : [테스트] 담당`(이사 이름)으로 나오면 **담당자 지정 방식의 한계**로 기록(초안은 소공인 역할 담당자를 신청인으로 씀)

## 정리

구글 캘린더의 시험 일정은 **직접 삭제**(보드는 캘린더 삭제를 하지 않음 — 과제 삭제 시 «남은 일정 n건» 안내가 뜨는지도 확인). 이후 과제 → 장비 → 담당자 2명 → 기관.

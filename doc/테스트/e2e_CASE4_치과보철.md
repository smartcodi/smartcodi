# E2E-04 · CASE 4 (필수) — 지르코니아 치과 보철 / 덴탈 CNC 밀링

공통 규칙·사전 조건은 [README](README.md). 중점: **추가공고 판정·필터**, **현장진단표 입력(휴대폰)**, **수행일지 1~3차·결과보고서 초안에 입력값이 그대로 들어가는지**.

## 사례 요약 (PDF 5쪽)

- 지르코니아 치과 보철물 제작. 사업자 등록 2년 전, 중고기계로 시작 → 장비 노후화
- 연매출 **2억원 미만**, 대표 1인 근무(거래처 증가로 채용 예정) → **추가공고**
- 사출 가공 이후 후처리 대부분 수작업. 문제: 정밀도 저하, 생산효율 감소, 유지관리비 증가 — **CNC 가공기 정상 작동**이 최우선 과제
- 수기이지만 **생산량 등 작업 결과를 데이터로 확보** → 도입 전후 비교 가능
- 기대: 티타늄 보철물 기준 **하루 6개 → 10개 정도**

| 구분 | 품목 | 규격 | 수량 | 단가·공급가 | 비고 |

| H/W | 덴탈 CNC 밀링기 | 마닉스 5SA | 1 EA | 42,000,000 | 5축 건/습식 밀링머신 (제조사 기재) |

## 보드 밖 확인

- 추가공고는 원공고와 **지원분야도 다르다**(CLAUDE.md). 치과 보철이 추가공고 지원분야에 해당하는지는 `doc/교재/99_…` 원문으로 따로 확인 — 보드는 판정하지 않음
- S/W 한도 = 4,666,666 / S/W 6,000,000 → **초과 1,333,334**

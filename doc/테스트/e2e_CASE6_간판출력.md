공통 규칙·사전 조건은 [README](README.md). 중점: **같은 공급사의 장비 카탈로그를 여러 과제가 공유(CASE5와 교차)**, **원문 사양 불일치 기록**, **삭제 규칙**, **전체 테스트 데이터 정리**. 6개 중 마지막에 실행한다.

- 사업 경력 30년 육박, 디자인~출력·후가공·시공 종합 처리

- 자체 개발 공정 파악 프로그램으로 견적 등 데이터 일부 관리. **견적 산출 신규 S/W** 기대 큼

## 전체 테스트 데이터 정리 (CASE 1~6 공통 마무리)

1. «과제» 탭 검색 `[테스트]` → 0건이 될 때까지 과제 삭제(자산 동반 삭제)
2. «장비» 탭 검색 `[테스트]`가 아닌 모델명으로 남은 시험 장비(FRANCIA·SMUS·ProdEX·하이테크·마닉스·Dentalsoft·LATEX·CNYX·QT-AI·RET) 삭제
3. «담당자» 탭 검색 `[테스트]` → 모두 삭제 (과제에 지정된 사람은 1에서 과제를 지웠으므로 풀려 있음)
4. «기관» 탭 검색 `[테스트]` → 모두 삭제
5. 구글 캘린더에서 `[스마트제조] [테스트]` 일정 삭제, Gmail 시험 메일 삭제(보드 밖)
6. 확인: `ArtifactData list` projects·accounts·contacts·products·assets 에 `[테스트]` 문서 없음. 예시 데이터(`isSample`)는 **그대로** 남아 있어야 함

### 1. S/W 한도 자동 계산·경고

- 배경: CLAUDE.md의 규칙 `S/W 한도 = min(H/W ÷ 9, 600만원)`로 계산하면 사례 6건 중 **5건이 초과**다(엑셀 `보드밖확인`). 보드는 이 계산을 하지 않는다. 규칙 원문 `doc/참고/작성원칙_요약.md`는 이 폴더에 없어 **미확인**이다.
- 선택지: (a) 넣지 않음 (b) 과제 상세 «도입 장비»에 H/W·S/W 합계와 한도 초과 경고 표시(자산 수량 × 장비 단가 기준) (c) (b) + 사업계획서 초안 사업비 칸 채우기
- 기본값: (a). 규칙 원문을 확인하지 못했고, 보드에 없는 수치를 만들지 않는다는 원칙과 충돌할 수 있다.
- 되돌리기: (b)는 화면 표시만이라 추가·제거가 쉽다.

### 2. 단가 자릿수 오기 검증

- 배경: CASE3 원문 합계 `6,600,00원`처럼 쉼표 자리가 틀린 값을 넣으면 쉼표를 떼고 **660,000원**으로 저장된다(C3-06에서 확인).
- 선택지: (a) 현행 (b) 쉼표가 있으면 3자리 묶음인지 검사해 틀리면 오류
- 기본값: (a). (b)는 한 줄 검사라 넣기 쉽다 — 원하면 바로 넣는다.

### 3. 신청인(대표) ≠ 소공인 역할 담당자일 때 서명란

- 배경: CASE3처럼 실무를 이사가 맡아 소공인 담당자를 이사로 지정하면, 수행일지 초안 서명란이 `신청인(대표) : [이사 이름]`이 된다(C3-14). 양식 서명란은 "신청인(대표)"다.
- 선택지: (a) 현행 (b) 소공인 기관의 `직함 = 대표` 담당자를 찾아 서명란에 쓰고, 없으면 빈칸 (c) 과제에 «대표자» 칸을 따로 둠
- 기본값: (a).

### 4. 인사말 기관명 생략 규칙(orgPrefix)

- 배경: 소공인 외 역할의 인사말은 기관명을 앞에 붙이되, **담당자 이름의 첫 단어가 기관명에 들어 있으면 생략**한다. 테스트 데이터(`[테스트] …`)에서 생략됐다(C2-06). 실데이터에서도 이름 첫 단어가 기관명과 겹치면(예: 기관 «한빛정밀», 이름 «한빛 영업») 생략된다.
- 기본값: 현행. 실제 인사말이 어색하게 나온 사례가 있으면 알려 달라.

### 5. 자산 → 양식 초안 연결

- 배경: 사업계획서 H/W·S/W 목록, 3차 진단 «④ 도입 장비», 결과보고서 4는 아직 자산을 읽지 않는다(C1-12에서 미연결 확인).
- 기본값: 미연결 유지. 연결하면 장비명·모델·수량·공급기업을 채울 수 있다(금액은 1번 결정과 함께).

### 6. 구글 드라이브 파일 관리 (보류)

- 배경: 과제 데이터 용량은 문제없다(실측 최대 5.9KB / 한도 256KB). 문제는 자료함이 한글·엑셀·워드를 못 받는 것.
- 권장안(보류 중): 과제별 드라이브 **폴더 링크** + 자료함 **링크 항목**(이름 + URL) — 커넥터 없이 가능. 커넥터 검색·업로드는 도구 확인 후.
- 상태: 사용자 결정으로 이번에는 연결하지 않음.
